Build-System Workflow

Author once in the GUI, sync from the CLI on every build

1. Select tracked content Pick leaf symbols or whole struct roots in the ELF inspector.
2. Save a sync project Commit the generated JSON file beside your A2L and ELF paths.
3. Run the CLI Use report for safe build failures or prune to remove stale tracked items.

Features

Everything you need for A2L calibration file management

A2L Editing

Create, open, and edit ASAP2/A2L files. Full editors for Measurement, Characteristic, and Axis Points entities with validation.

ELF Binary Import

Import symbols from ELF binaries with DWARF debug info. Smart type inference, struct member expansion, and array support.

CLI Sync Projects

Save versioned sync-project JSON files from the GUI and run repeatable opent_a2l_forge_cli sync --project ... updates in your build system.

Manual Entity Creation

Create all 6 major A2L entity types directly from the UI: Measurements, Characteristics, AxisPts, CompuMethods, CompuVtabs, and RecordLayouts.

A2L Validator

Built-in validation engine with 9 rules: cross-reference checks, duplicate name detection, limit inversion warnings, and address validation.

Conflict Resolution

Detect and resolve symbol conflicts during import. Preview changes before applying, with skip, replace, and batch options.

Nested Struct Sync

Track top-level struct roots and import newly added nested leaves automatically while preserving safe stale-item reporting.

Live ELF Watching

Automatically detect ELF file changes and update ECU addresses. Stay in sync with your build system without manual re-imports.

Modular Architecture

Clean separation of concerns across frontend and backend

Rust Backend

  • lib.rs — Tauri wrappers + AppState
  • types.rs — Shared types and traits
  • a2l_ops.rs — A2L CRUD + tree building
  • elf_parser.rs — ELF/DWARF parsing
  • cli_sync.rs — Project loading + headless sync engine
  • validator.rs — A2L validation engine

React Frontend

  • Layout: TitleBar, MenuBar, ActivityBar, StatusBar
  • Panels: Explorer, ELF Inspector, Entity Detail, Settings
  • Dialogs: Create, Delete, Conflict, Preview, Unsaved
  • Editors: Measurement, Characteristic, AxisPts, CompuMethod, CompuVtab, RecordLayout
  • CLI authoring: save/load sync projects from the ELF workflow
